- **Simple controls:** Sage independently challenged the lead's plan against the actual panel and the [usability guide](usability-principles.md). Build identifiers are developer evidence, not a player setting. Manual update checking remains secondary and becomes immediately reachable on update failure. Never hide Cancel with the travel options.
- **Current themes work offline:** both small current theme closures are cached, including all four WOFF2 files, baked wordmarks and required notices. The fonts total 37,428 bytes. `tools/pwa/theme-packs.ts` declares both themes and a separate 64 KiB font budget; its typed key set forces explicit review when ThemeId expands. Every emitted font must match a declared source hash, without aliases or omissions. The full app still has its separate 8 MiB budget. This is not an unlimited future theme-pack policy or a new runtime pack manager.
- **Real file types:** Sage and the lead independently found that WOFF2 fell through the old worker MIME check. A media type tells the browser what a response contains. Exact type parsing now covers scripts, fonts and other current files; a misleading header parameter cannot pretend to be JavaScript. Wrong MIME with otherwise correct bytes must fail readiness. The native regression upgrades the real earlier Pond PWA to the combined build so the chosen font URL is actually new and cannot be reused from the old cache.
- **Safe theme recovery:** main's direct Reload actions have no save barrier. Retry already handles renderer failures and supported font fallback separately. Remove direct reloads while preserving Retry, unsaved recovery export and save/close-all/reopen guidance, including initial renderer failure and a later failed theme switch.
- **Future icons:** Cora challenged the actual renderer and W3C mask geometry. Dynamic Playwright import fixes the demonstrated local-browser-path initialization bug. One real regeneration left all three PNGs byte-identical. The tool does not automatically pad arbitrary future art; [the recipe](pwa-icons.md) explains source rights, safe geometry and separate maskable sources.
