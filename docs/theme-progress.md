Wonky substitutions are disabled at these small sizes, so enabling that axis would not provide the promised personality. Its [display classification](https://raw.githubusercontent.com/google/fonts/main/ofl/fraunces/DESCRIPTION.en_us.html) was a reason to test real compact UI rather than assume suitability. The extra wrap in Auto's German countdown is accepted in the existing scrolling dialog, preserving type size and access to every setting.

The fallback is native-first: `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Arial, sans-serif`. Roboto/Arial are explicit installed alternatives before the generic sans-serif. Typical native results are Segoe UI, San Francisco or Roboto, depending on device/browser/settings. No fallback downloads another font and no Times/serif generic is requested. Downloading a fashionable fallback was rejected because it adds bytes and another failure path without improving this recovery role. Runtime publication and the initial CSS share this chain.
