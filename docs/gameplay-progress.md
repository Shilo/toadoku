### P001: overall architecture, dependency and validation direction

Lead proposal: pure domain modules, immutable certified progressive catalog, one application-lifetime coordinator, transactional repository and preserved Pond presentation. Sequence rules/catalog/storage foundations, session/modes/hints, presentation, then full adversarial integration. Integrate and commit coherent accepted slices throughout. Run complementary independent algorithms, emitted-data joins, model tests, failure interleavings and lead-owned Codex browser journeys. No worker report is acceptance.

Research: [Norvig rules](https://www.norvig.com/sudoku.html), [Knuth exact cover](https://arxiv.org/abs/cs/0011047), [IndexedDB transaction specification](https://www.w3.org/TR/IndexedDB/), [publisher dataset policy](https://sudokuexchange.com/puzzle-bank/), [Vite assets](https://vite.dev/guide/assets.html). Applicability: pure classic rules, structurally different exact oracle, atomic browser records and repository-relative public assets.

Challengers: Rowan and Sage. Rowan's strongest counterexample: two valid attempts bound to one frontier can both claim an attempt receipt. Resolution: distinct generation/run/Leap/schedule grant plus transactional tuple CAS. Timer/notes saves must not starve hints; logical premise revision is independent of persistence revision. Sage challenged coalesced whole-profile writes and loss of committed knowledge. Resolution: coalescing only attempt snapshots; current wallet delta inside the completion transaction; immutable definition/status checks, monotone assistance union and elapsed maximum; disclosure barrier drains/rebases compatible state. Global essential revision gates restore activation only, while ordinary saves compare generation/attempt/writer to avoid unrelated-role livelock. No locks/messages grant authority.

Rejected alternatives: shared solver wrappers as independent certification, localStorage accounting, startup whole-corpus parsing, UI-owned wallet/session state and unload-only persistence. Required evidence is every gate in the validation matrix. Direction agreed with named challengers; actual implementation remains unaccepted.

Cora challenged manifest overhead and old-root retention; measured payload gates and full independent membership certification are mandatory. The previous 100k certificate is invalidated by this material pipeline change and will be regenerated.
